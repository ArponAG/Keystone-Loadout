# Keystone Loadout

Personal WoW Retail companion app.

- **Build Gear Finder** — rank gear per slot by stat fit
- **Dungeon Loot Directory** — current season loot tables
- **Character Lookup** — Raider.IO profiles
- **News Feed** — Wowhead RSS

Stack: Next.js 15 (App Router) · TypeScript · Tailwind · Drizzle + SQLite
